# Vila Serena Next

Bem-vindo ao repositório do **Vila Serena Next**, uma aplicação web focada em excelência em hospitalidade, projetada para oferecer uma experiência de usuário premium e responsiva. O projeto foi estruturado a partir de um design moderno com uma arquitetura robusta em **Next.js**, utilizando **Tailwind CSS** e **Shadcn UI**.

## 🏨 Sobre o Projeto

Este é um site de portfólio projetado para redes hoteleiras e hospitalidade de luxo. Entre as suas principais seções estão:
- **Hero:** Uma área de destaque introdutória imersiva e com navegação.
- **Essence:** A apresentação da essência, conforto e dos valores da marca.
- **Accommodations:** Apresentação detalhada das acomodações premium com apelo visual.
- **Dining:** As incríveis experiências gastronômicas exclusivas oferecidas aos hóspedes.

A UI foi construída para exibir elegância com sua paleta de cores em **verde musgo**, e uma responsividade meticulosa que abrange perfeitamente desde dispositivos móveis (com uma experiência mobile-first) até monitores widescreen (ex: adaptação refinada para telas 1366x768).

## 🚀 Stack de Tecnologias

- [Next.js](https://nextjs.org/) (App Router)
- [React](https://reactjs.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Shadcn UI](https://ui.shadcn.com/)
- TypeScript

## 📦 Inicialização Rápida

### 1. Clonar o Repositório

```bash
git clone https://github.com/nobreaz/forge-hotel-template.git
cd forge-hotel-template
```

### 2. Instalar Dependências

Utilize o gerenciador de pacotes npm (ou o de sua preferência) para instalar as dependências:

```bash
npm install
```

### 3. Rodar o Ambiente de Desenvolvimento

```bash
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no seu navegador para explorar o projeto. O ambiente possui hot-reload ativado para as modificações nos arquivos.

## 🛠 Comandos Disponíveis

- `npm run dev` - Roda a aplicação em modo de desenvolvimento local.
- `npm run build` - Gera os arquivos estáticos otimizados para produção.
- `npm run start` - Roda o servidor web utilizando a build de produção.
- `npm run lint` - Checa padrões de desenvolvimento (ESLint).

## 📱 Responsividade e UI

Focamos na máxima acessibilidade visual, incluindo menus laterais (Sheets) perfeitamente posicionados em dispositivos mobile, evitando sobreposições em componentes sensíveis para melhorar a jornada diária dos usuários.
